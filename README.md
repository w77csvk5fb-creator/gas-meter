# ガソリン代メーター

車で走った距離から、消費したガソリンの量とガソリン代を計算する iPhone 向けの Web アプリです。Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。

## できること

- **自動で計測**：アプリを開いている間、走り出すと計測を始め、止まって数分たつと到着として記録します
- **手動でも操作可能**：「今すぐ出発」「到着」ボタンでいつでも開始・終了できます
- **到着時に通知**：ガソリン代と消費量を通知します（ホーム画面から開いたとき）
- **単価・燃費をその場で調整**：走行画面の −／＋ で微調整。gogo.gs で近くのスタンドの価格を確認できます
- **履歴**：月ごとの合計金額・消費量・距離

計算式：`距離 ÷ 燃費 × ガソリン単価`

## 注意

- iPhone の仕様上、Web アプリは閉じている間や画面が消えている間は位置情報を取得できません。計測中はアプリを開いたままにしてください（画面は自動で消えないようにしています）
- 記録や設定はその iPhone の中だけに保存され、外部には送信されません

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 計測・計算・保存の処理 |
| `styles.css` | 見た目（ダークモード対応） |
| `sw.js` | オフライン対応と通知（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 |
| `icons/` | アプリアイコン |

更新するときは `sw.js` の `CACHE` の番号を上げると、iPhone 側に新しい版が届きます。
