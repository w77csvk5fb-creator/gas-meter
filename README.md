# ガソリン代メーター

走った距離を入力すると、消費したガソリンの量とガソリン代を計算して記録する iPhone 向けの Web アプリです。Safari で開いて「ホーム画面に追加」すると、アプリのように使えます。

## できること

- **距離から計算**：走行距離（km）を入れると、ガソリン代と消費量をその場で表示します
- **記録**：「記録する」で履歴に残し、月ごとの合計金額・消費量・距離を表示します
- **単価・燃費をその場で調整**：計算画面の −／＋ で微調整できます。gogo.gs で近くのスタンドの価格を確認できます

計算式：`距離 ÷ 燃費 × ガソリン単価`

記録や設定はその iPhone の中だけに保存され、外部には送信されません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 計算・保存の処理 |
| `styles.css` | 見た目（ダークモード対応） |
| `sw.js` | オフライン対応（Service Worker） |
| `manifest.webmanifest` | ホーム画面に追加したときの設定 |
| `icons/` | アプリアイコン |

更新するときは `sw.js` の `CACHE` の番号を上げると、iPhone 側に新しい版が届きます。
